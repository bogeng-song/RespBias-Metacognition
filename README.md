> **Official repository for the manuscript:**
> Song, B., & Rahnev, D. (2026). *Self-monitoring in perceptual decisions by humans and machines*.

## 📖 Overview

Perceptual confidence is typically conceptualized as monitoring stimulus uncertainty. This project investigates whether humans and Artificial Neural Networks (ANNs) go beyond stimulus uncertainty by engaging in **self-monitoring** of their own decisional tendencies (response biases).

Using multi-alternative (4- and 8-choice) perceptual decision-making tasks, mixed-effects regressions, and hierarchical Bayesian mediation, we demonstrate:

1. **Humans** naturally down-weight their confidence when biased toward a specific response (a negative direct effect of bias on confidence).
2. **Standard ANNs** (AlexNet, ResNet18, VGG19-BN) do *not* self-monitor; response bias inflates their confidence.
3. **Metacognitive ANNs**, augmented with a novel unsupervised self-monitoring module, successfully reproduce the human-like negative bias–confidence relationship.

## ⚙️ Installation

**1. Clone the repository**
```bash
git clone https://github.com/bogeng-song/RespBias-Metacognition.git
cd RespBias-Metacognition
```

**2. Create the conda environment**

Because this project uses PyMC for Bayesian modeling, we strongly recommend installing via `conda-forge` to avoid C-compiler issues:
```bash
conda create -n metacog -c conda-forge python=3.11 pymc pytensor arviz -y
conda activate metacog
pip install -r requirements.txt
```

**3. Download data and model weights**

Due to GitHub file-size limits, the behavioral data and 180 pre-trained ANN instances are hosted externally:

- 🔗 **[OSF Repository](https://osf.io/nz25w/overview?view_only=36e5bcc2225f4b55a54b77b5f690d786)** — human behavioral CSVs
- 🔗 **[Google Drive](https://drive.google.com/drive/folders/1DlBBSSz3avxgukT13VW2zkMaTNDQ7qdV?usp=sharing)** — pre-trained ANN weights

Place the behavioral CSVs in `data/human_data/` and the ANN weight files in a `weights/` directory at the project root.

After downloading, your `data/human_data/` folder should contain:
```
Experiment1_4_choice.csv
Experiment1_8_choice.csv
Experiment2_accuracy.csv
Experiment2_speed.csv
```

## 🚀 Reproduction Guide

The codebase has two independent tracks: the **Human Behavioral Pipeline** and the **ANN Pipeline**. Both feed into the same statistical analysis and figure-generation code.

---

### Track 1 — Human Behavioral Pipeline

#### Step 1 · Preprocess raw data

Convert trial-level CSVs into the per-subject × per-digit aggregated format
required by the regression and mediation modules. Run once for each of the four datasets:

```bash
# Experiment 1 — 8-choice (digits 1–8)
python scripts_analysis/preprocess.py \
    --input  data/human_data/Experiment1_8_choice.csv \
    --output data/human_data/Experiment1_8_choice_aggregated.csv \
    --condition 8choice

# Experiment 1 — 4-choice (digits 5–8)
python scripts_analysis/preprocess.py \
    --input  data/human_data/Experiment1_4_choice.csv \
    --output data/human_data/Experiment1_4_choice_aggregated.csv \
    --condition 4choice

# Experiment 2 — Accuracy-focus condition
python scripts_analysis/preprocess.py \
    --input  data/human_data/Experiment2_accuracy.csv \
    --output data/human_data/Experiment2_accuracy_aggregated.csv \
    --condition exp2

# Experiment 2 — Speed-focus condition
python scripts_analysis/preprocess.py \
    --input  data/human_data/Experiment2_speed.csv \
    --output data/human_data/Experiment2_speed_aggregated.csv \
    --condition exp2
```

Each run prints a validation summary (subject count, digit count, NaN checks, and value ranges) so you can confirm the output looks correct before continuing.

#### Step 2 · (Optional) M-SDT parameter estimation

Estimates latent sensitivity (*d'*) and category-specific bias (*b*) using a Bayesian generative model. Used for the supplementary analyses; you can skip this if you only want to reproduce the main figures.

```bash
# Experiment 1, 8-choice
python scripts_analysis/msdt_model.py \
    --data_path  data/human_data/Experiment1_8_choice.csv \
    --output_path data/human_data/Experiment1_8_choice_MSDT.csv \
    --n_alts 8 --draws 2000 --tune 1000 --chains 4

# Experiment 1, 4-choice
python scripts_analysis/msdt_model.py \
    --data_path  data/human_data/Experiment1_4_choice.csv \
    --output_path data/human_data/Experiment1_4_choice_MSDT.csv \
    --n_alts 4 --draws 2000 --tune 1000 --chains 4
```

> ⚠️ MCMC sampling runs subjects in parallel using joblib. Allow ~30–60 min per dataset depending on hardware.

#### Step 3 · Generate Figure 2

Figure 2 shows (A) the theoretical simulation relating response bias to optimal confidence, and (B) an example participant's scatter plots for both conditions:

```bash
python notebooks/figure2.py \
    --data4 data/human_data/Experiment1_4_choice.csv \
    --data8 data/human_data/Experiment1_8_choice.csv \
    --output figure2.pdf
```

**Optional arguments:**

| Argument | Default | Description |
|---|---|---|
| `--example_sub` | `12` | `Sub_id` of the example participant shown in Panel B |
| `--output` | `figure2.pdf` | Output path (`.pdf`, `.png`, or `.svg`) |
| `--fontsize` | `11` | Base font size for all text elements |

To find a different representative participant, you can loop over subject IDs and inspect the output, or choose one that clearly shows the sign-reversal pattern described in the manuscript.

#### Step 4 · Regression and mediation analyses (Figures 3–6)

Open the analysis notebook, which imports `regression.py` and `mediation.py` and runs all four conditions automatically:

```bash
conda activate metacog
jupyter notebook notebooks/Regression_Mediation.ipynb
```

**What the notebook covers:**
- Experiment 1 (4-choice): regression + Bayesian mediation → Figure 3
- Experiment 1 (8-choice): regression + Bayesian mediation → Figure 3
- Experiment 2 Accuracy-focus: regression + Bayesian mediation → Figure 4
- Experiment 2 Speed-focus: regression + Bayesian mediation → Figure 4
- ANN Baseline (AlexNet, ResNet18, VGG19-BN): regression + mediation → Figure 5
- ANN Metacognitive: regression + mediation → Figure 6

> ⚠️ The Bayesian mediation steps call PyMC NUTS sampling and take ~5–15 min per condition. Run sequentially or use the saved trace files if available.

> **Note on Figures 3–6:** The regression bar-chart panels are generated directly by the notebook. The mediation path-diagram panels (showing path coefficients with arrows) are drawn manually using the numerical outputs; the notebook prints all posterior means and HDI intervals needed to construct them.

### Track 2 — ANN Pipeline

#### Step 1 · Train base models

Trains standard CNNs on 224×224 MNIST. Each architecture requires 60 independent instances with different random seeds. Use a loop or a job scheduler:

```bash
for i in $(seq 0 59); do
    python scripts_ann/train.py \
        --model alexnet \
        --instance $i \
        --save_dir ./weights/alexnet/
done
# Repeat with --model resnet18 and --model vgg19
```

> Pre-trained weights for all 180 instances are available on Google Drive (see Installation). You can skip training and go directly to evaluation.

#### Step 2 · Evaluate standard (baseline) behavior

Calibrates Gaussian noise to match human accuracy (~64%) and extracts confidence as the top-2 z-scored logit difference:

```bash
python scripts_ann/test_baseline.py \
    --model     alexnet \
    --model_dir ./weights/alexnet/ \
    --output_dir ./data/model_data/base/ \
    --target_acc 0.64
# Repeat for resnet18 and vgg19
```

#### Step 3 · Apply the metacognitive module

Runs the unsupervised self-monitoring mechanism — computes the *S_k* penalty from the training-set response distribution and applies it during test evaluation:

```bash
python scripts_ann/test_metacognitive.py \
    --model      alexnet \
    --model_dir  ./weights/alexnet/ \
    --output_dir ./data/model_data/meta/ \
    --noise_level 1.19   # Use the value printed by test_baseline.py
# Repeat for resnet18 and vgg19
```

The output CSVs from both scripts use the same column schema as the human data and can be fed directly into the `Regression_Mediation.ipynb` notebook for statistical analysis.

## 📝 Notes on Reproducibility

- All random seeds for ANN training are derived deterministically from the instance index, ensuring exact reproducibility across runs.
- Mixed-effects models use a 3-tier fallback (random slopes → random intercepts → cluster-robust OLS) to handle convergence issues in repeated-measures data. The tier used for each model is printed to the console.
- Bayesian models use NUTS sampling with `target_accept=0.95` and convergence is assessed via R-hat (threshold < 1.01).
- The `preprocess.py` FAR computation for Experiment 2 uses only trials within the provided CSV file (accuracy-focus or speed-focus separately). The original analysis computed FAR across all trials for a subject before splitting by condition; the practical difference between the two approaches is small (< 0.006 per digit per subject).
