## 📖 Overview
Perceptual confidence is typically conceptualized as monitoring stimulus uncertainty. This project investigates whether humans and Artificial Neural Networks (ANNs) go beyond stimulus uncertainty by engaging in **self-monitoring** of their own decisional tendencies (response biases). 

Using multi-alternative (4- and 8-choice) perceptual decision-making tasks, mixed-effects regressions, and hierarchical Bayesian mediation, we demonstrate:
1. **Humans** naturally down-weight their confidence when biased toward a specific response (a negative direct effect of bias on confidence).
2. **Standard ANNs** (AlexNet, ResNet18, VGG19) do *not* self-monitor; response bias inflates their confidence.
3. **Metacognitive ANNs**, augmented with a novel unsupervised self-monitoring module, successfully reproduce the human-like negative bias-confidence relationship.

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bogeng-song/RespBias-Metacognition.git
   cd RespBias-Metacognition
   ```

2. Create a virtual environment and install dependencies. Because this project uses `PyMC` for Bayesian modeling, we highly recommend using `conda-forge` to prevent C-compiler issues:
   ```bash
   conda create -n metacog -c conda-forge python=3.11 pymc pytensor arviz -y
   conda activate metacog
   pip install -r requirements.txt
   ```

3. **Data Availability & Pre-trained Models:** 
   Due to GitHub file size limits, raw human behavioral data and the 180 pre-trained ANN model instances (60x AlexNet, 60x ResNet18, 60x VGG19) are hosted on the Open Science Framework (OSF):
   🔗 **[Link to OSF Repository](https://osf.io/[YOUR_OSF_LINK])**
   
   *Extract the downloaded behavioral files into the `data/human_data/` directory, and the ANN weights into a `weights/` directory before running the pipelines.*

## 🚀 Usage & Reproduction Guide

The codebase is split into two independent tracks: **Statistical Analysis** (Human/Model Behavior) and the **ANN Pipeline** (Training & Metacognitive Testing).

### Phase 1: Statistical Analysis (Behavioral Pipeline)

The `scripts_analysis` folder contains the tools to extract behavioral parameters and run the core statistical tests presented in the manuscript.

**A. Multi-Alternative Signal Detection Theory (M-SDT) Estimation**  
Extracts latent sensitivity ($d'$) and response bias ($b$) using a Hierarchical Bayesian Generative Model. It automatically adapts to single-noise (Exp 1) or multi-noise (Exp 2) task designs.
```bash
# Experiment 1 (Single Noise Level)
python scripts_analysis/msdt_model.py \
    --data_path data/human_data/dataset1/data_for_SDT.csv \
    --output_path data/human_data/dataset1/MSDT_Results.csv \
    --n_alts 8 --draws 2000 --tune 1000 --chains 4
```

**B. Mixed-Effects Regression**  
(Run via import in the Jupyter Notebooks)  
Isolates the direct effect of Response Bias on Confidence while controlling for Accuracy and RT. It utilizes a robust 3-tier fallback strategy (Random Slopes $\rightarrow$ Random Intercepts $\rightarrow$ Cluster-Robust OLS) to elegantly handle matrix singularity issues inherently found in repeated-measures data.

**C. Bayesian Multilevel Mediation**  
(Run via import in the Jupyter Notebooks)  
Decomposes the relationship into indirect paths (Bias $\rightarrow$ Accuracy $\rightarrow$ Confidence) and the critical direct path (Bias $\rightarrow$ Confidence) using PyMC NUTS sampling.

*(Note: `regression.py` and `mediation.py` are built as importable modules utilized directly within the Jupyter Notebooks to keep figure generation scripts clean).*

---

### Phase 2: Artificial Neural Network (ANN) Pipeline

The `scripts_ann` folder contains the PyTorch Lightning pipelines to reproduce the machine learning experiments.

**A. Train Base Models**  
Train standard object-recognition networks on 224x224 MNIST. To replicate our 60 random initializations, run this in a bash loop (`--instance 0` to `59`).
```bash
python scripts_ann/train.py --model alexnet --instance 0 --save_dir ./weights/alexnet/
```

**B. Evaluate Standard ANN Behavior (Baseline)**  
Calibrates the visual noise added to the stimuli to match the human accuracy benchmark (~64%), and extracts standard naive confidence (Top-2 Logit Difference).
```bash
python scripts_ann/test_baseline.py \
    --model alexnet \
    --model_dir ./weights/alexnet/ \
    --output_dir ./data/model_data/base/ \
    --target_acc 0.64
```

**C. Apply the Metacognitive Module**  
Implements the unsupervised self-monitoring mechanism. The module computes the $S_k$ penalty based on the inverse empirical CDF of choice frequencies, operating completely without trial-by-trial accuracy feedback.
```bash
python scripts_ann/test_metacognitive.py \
    --model alexnet \
    --model_dir ./weights/alexnet/ \
    --output_dir ./data/model_data/meta/ \
    --noise_level 1.19
```

### Phase 3: Analyzing Model Outputs & Plotting

Because the ANN pipeline (`test_metacognitive.py`) outputs data in the exact same format as the human trials, the CSVs can be processed directly by the human statistical scripts symmetrically! 

All figures for the manuscript can be generated by running the notebooks in the `notebooks/` directory, which automatically imports the analysis modules and the custom Matplotlib utilities from `notebooks/visualization.py`.

```bash
jupyter notebook
```
